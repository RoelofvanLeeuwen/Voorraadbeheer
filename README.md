# Voorraadbeheer

Persoonlijke voorraadbeheerapplicatie voor een hobbyschuur.

Houdt bij welke materialen, bevestigingsmiddelen en machines/gereedschappen er zijn, in welke hoeveelheid, en of iets is uitgeleend. Via projecten kan de gebruiker vooraf zien wat er ontbreekt.

## Technologie

- .NET (hoogste stabiele versie op de machine)
- Server-side Blazor
- Clean Architecture
- SQLite via EF Core
